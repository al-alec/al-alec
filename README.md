## Selected Open Source Projects

### Wav2Vec-BERT Audio Sentiment Analyzer  
[GitHub Repository](https://github.com/al-alec/audio-sentiment-analyzer)

End-to-end system for audio emotion recognition using Wav2Vec 2.0 for transcription and BERT for sentiment analysis.  
Includes a Gradio interface, API, and real-time inference demo.

**Stack:** PyTorch, Transformers, Gradio, FastAPI, NumPy

---

### ioumatch  
[PyPI Package](https://pypi.org/project/ioumatch/)

Python library published on PyPI for computing IoU-based matching metrics in segmentation tasks.  
Lightweight and NumPy-based, designed for binary and multi-label masks.

**Stack:** NumPy, OpenCV, Scikit-Image, Python Packaging
